# Sales Closing SOP

## Sales Promise

Install a managed Lost Revenue Recovery System for independent medspas, using their existing tools, without asking them to migrate to a new SaaS platform.

The promise is not "more automation." The promise is to recover revenue from missed consults, no-shows, cold leads, lapsed VIP clients, weak review capture, and inconsistent referral asks.

## Discovery Call Structure

1. Open with context:
   - "I want to understand where revenue is leaking before I recommend anything."
2. Diagnose:
   - Monthly inquiries
   - Booking rate
   - No-show rate
   - Review process
   - Rebooking process
   - Lapsed client process
   - Current tools
3. Quantify:
   - Average treatment value
   - Missed inquiries per month
   - No-shows per month
   - Lapsed high-value clients
4. Demo:
   - Overview dashboard
   - Pipeline
   - Alerts
   - Settings/readiness
   - Workflow map
5. Recommend:
   - "Based on what you told me, the first win is X."
6. Close:
   - "Do you want me to install this for your clinic this week?"

## Demo Flow

| Minute | What to show | Point |
|---|---|---|
| 0-2 | Dashboard overview | Owner gets one clean operating surface. |
| 2-5 | Pipeline | Every lead/client has a status and next action. |
| 5-8 | Critical alerts | The system surfaces what staff miss. |
| 8-11 | Workflows | Follow-up runs without manual chasing. |
| 11-13 | Settings/readiness | This is controlled, owned, and launchable. |
| 13-15 | Price + next step | Make the decision simple. |

## Objection Handling

| Objection | Response |
|---|---|
| "We already have a booking system." | "Good. This sits around it. Your booking system holds the calendar. This recovers the missed consults, no-shows, cold leads, reviews, referrals, and lapsed VIPs that usually fall between the cracks." |
| "Can my staff just do this?" | "They can, but consistency is the problem. This makes the important follow-up happen every time." |
| "Is this SaaS?" | "No. It is a managed system installed around your accounts. You own the sheet, inbox, workflows, and data." |
| "Will it guarantee more revenue?" | "No honest operator should guarantee that. What it does is recover the specific moments where revenue is already leaking and make those actions visible every week." |
| "We need to think about it." | "Fair. What specifically needs to be true for you to say yes or no?" |

## Flagship Demo Story

Use this order on calls:

1. "Here is where leads and appointments leak."
2. "Here is how the dashboard surfaces those leaks."
3. "Here is how the workflows recover them."
4. "Here is how the weekly report proves what happened."
5. "Here is the setup and monthly investment."

Do not start with workflow count. Start with lost revenue, then show the machine.

## Proposal Rules

- Send same day.
- Include the specific pain from the call.
- Include one recommended package, not a menu unless asked.
- Include setup timeline and what access is needed.
- Follow up at 24 hours, 72 hours, 7 days, then nurture.

## Close Criteria

A deal is closed only when:

- Setup fee paid.
- Scope accepted.
- Client intake completed.
- Delivery start date scheduled.
