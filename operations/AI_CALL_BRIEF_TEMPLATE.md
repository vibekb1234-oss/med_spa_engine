## Questions To Ask

1. How many new inquiries does the clinic usually get each month?
2. How quickly are new inquiries followed up?
3. What happens when someone no-shows or cancels late?
4. How often are lapsed Botox, filler, laser, or facial clients reactivated?
5. Who checks whether reviews, referrals, and weekly reporting are actually happening?

## Objections To Expect

| Objection | Response angle |
|---|---|
| We already have a booking system | This installs around the booking system; it does not replace it. |
| We already send reminders | The system covers reminders plus no-show recovery, cold leads, reviews, referrals, VIP reactivation, and reporting. |
| I need to think about it | Ask what specifically needs to be true before they would install it. |
| Is this guaranteed? | Installation and visibility are guaranteed, not revenue or bookings. |
