Welcome

You are about to set up MedSpa Growth Engine.

This wizard walks through the install in about 25 minutes. Take it one step at a time - each step is independently saved, so you can close this tab and pick back up later.

What you will end with

  • A configured Google Sheet that holds clients, appointments, and activity log
  • Eight n8n workflows running 24/7 with Gmail and Google Sheets credentials wired
  • A self-hosted dashboard with first-run admin account and signed kanban
  • A weekly performance report scheduled to the clinic owner
  • One webhook secret shared correctly across n8n, the dashboard, Apps Script, and the intake form

What you need before starting

  • Access to the clinic's Google Workspace account (for Sheets + Gmail OAuth)
  • An n8n cloud account, or a self-hosted n8n instance (~$20/month tier is fine)
  • The clinic's Google Maps review link
  • The clinic's IANA timezone (e.g. America/New_York)
  • A modern browser - Chrome, Safari, Edge, or Firefox
Heads up: the OAuth steps in n8n require the clinic's Google login. Most operators do this on a 10-minute screen share with the clinic owner.

Step 3 of 7

Google Sheet + Apps Script

This creates the CRM and activity log that every workflow reads from.

3.1 Create a new Google Sheet

  1. While signed in to the clinic's Google account, open sheets.new
  2. Rename it: [Clinic Name] - MedSpa Growth Engine
  3. Copy the Sheet ID from the URL (the long string between /d/ and /edit)

3.2 Paste the Apps Script

  1. In the new Sheet, go to Extensions → Apps Script
  2. Delete the default function myFunction() stub
  3. Open setup/MedSpa_Engine.gs in this repo, copy the entire contents, and paste them in
  4. At the top, set WEBHOOK_SECRET and CLINIC_TIMEZONE to the values you will use in n8n
  5. Save (the floppy disk icon), then run the function setupMedSpaEngine
  6. Authorize the script when prompted - this is a one-time consent
What this does: creates the three tabs (Clients, Appointments, Activity Log) with correct headers, seeds demo data, and installs a custom menu. Safe to re-run.

3.3 Generate the webhook secret

This is the shared password between n8n, the dashboard, and the Apps Script. Same value used in all three places.

Open Workflow Configurator (has a generator)
Step 4 of 7

n8n credentials

Connect Gmail and Google Sheets to the clinic's n8n instance. Both use OAuth2 and require the clinic's Google login - this is the step that usually needs a screen share.

4.1 Sign in to n8n

  1. Open the clinic's n8n instance (e.g. https://[clinic].app.n8n.cloud)
  2. Go to Credentials in the sidebar

4.2 Add Google Sheets OAuth2

  1. Click Add credential → Google Sheets OAuth2 API
  2. Click Sign in with Google and authorize with the clinic's Google account
  3. Save the credential - copy its ID from the URL (the part after /credentials/)

4.3 Add Gmail OAuth2

  1. Click Add credential → Gmail OAuth2
  2. Sign in with the same clinic Google account so all outgoing email is from the clinic, not from you
  3. Save and copy the credential ID
Important: emails will be sent as the Google account you signed in with. Use the clinic's actual reply-to address, not yours.
Step 5 of 7

Configure + import all 8 workflows

The configurator takes your 8 values and produces 8 ready-to-import JSON files.

5.1 Open the configurator

Fill in the values from the previous steps and download each configured workflow.

Open Workflow Configurator
Required: Sheet ID, Sheets credential ID, Gmail credential ID, clinic email, clinic name, review link, webhook secret, IANA timezone.

5.2 Import each workflow

  1. In n8n, click Workflows → Import from File
  2. Import all 8 configured files one at a time
  3. Open each, click Activate in the top right

5.3 Copy the 4 webhook URLs

Open workflows 1, 3, 6, and 8 in n8n. Each starts with a Webhook node - copy its Production URL. Paste them here so you have them for the dashboard step.

Step 6 of 7

Dashboard first-run setup

The dashboard creates the admin account on first load and pulls all client data from the Sheet.

6.1 Open the dashboard

  1. Host dashboard/index.html somewhere the clinic team can reach (e.g. Netlify, Vercel, or even a local file)
  2. Open it in Chrome
  3. The first-run setup creates the ADMIN account - set a passcode the owner remembers

6.2 Connect to the Sheet

  1. Log in to the dashboard as ADMIN
  2. Go to Settings → System
  3. Paste your Google API key, Sheet ID, and webhook secret
  4. Paste the 4 webhook URLs from Step 5.3
  5. Click Test connection - you should see "Connected ✓"
API key restrictions: create the API key in Google Cloud Console, restrict to the Sheets API only, and add the dashboard's domain as an HTTP referrer. Never use an unrestricted key.

6.3 Back up the config

Settings → System → Export config. This downloads a JSON file with your dashboard configuration. Keep it somewhere safe - if the browser localStorage gets cleared you can restore from this file.
