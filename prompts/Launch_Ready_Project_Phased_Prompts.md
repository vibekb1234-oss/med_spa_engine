# Launch Ready Project Phased Prompts

Use these prompts to continue launch work without drifting from the MedSpa Growth Engine offer.

## Phase 1 - Live Setup

Connect the final domain, Vercel project, Supabase project, email inbox, and dashboard protection. Verify all clean URLs and security headers.

## Phase 2 - Auth And Profile

Run the Supabase schema, configure auth providers, test `/login`, `/signup`, `/reset`, `/auth/callback`, and verify profile rows are created on signup.

## Phase 3 - Client Delivery Wiring

Create a demo client Google Sheet, configure all 8 n8n workflows, set webhook secret, connect OAuth, and run the system check.

## Phase 4 - Mobile QA

Test landing, booking, auth, dashboard, and tools at 390px width. Fix overflow, cramped buttons, broken drawers, and unreadable screenshots.

## Phase 5 - Sales Launch

Run the first 50-lead research batch. Draft pain-specific outreach from `operations/AI_LEAD_RESEARCH_AND_PERSONALIZATION.md`. Send only the first 10 manually until reply quality is proven.

## Phase 6 - First Client Handoff

Use `operations/Client_Deployment_Runbook.md` and `operations/Pre_Handoff_QA_Checklist.md`. Do not hand over until workflow QA, dashboard protection, backup, and reporting are complete.
